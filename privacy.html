INFORMATIONS SUR LES DONNÉES

Politique de confidentialité

Version bêta — 20 novembre 2026

1. État actuel du service

Maths2.0 est actuellement une application expérimentale sans création de compte, sans paiement intégré et sans synchronisation de la progression entre appareils. Cette page décrit les traitements visibles dans la version actuelle du code ; elle ne remplace pas la validation juridique nécessaire avant une commercialisation.

2. Données conservées sur l'appareil

La progression est enregistrée dans le stockage local du navigateur (localStorage) : notions travaillées, exercices réussis, tentatives, révisions programmées, statistiques de session et brouillons saisis dans les exercices. Ces informations restent dans le navigateur utilisé et ne sont pas synchronisées par l'application avec un compte utilisateur.

La fonction de réinitialisation de la progression permet d'effacer les données locales gérées par l'application. La suppression du stockage du navigateur peut également les effacer.

3. Tuteur IA (fonctionnalité distincte et facultative)

Lorsque l'utilisateur choisit d'utiliser le tuteur IA, le texte de ses messages et, le cas échéant, l'image jointe sont transmis par une requête HTTPS au Worker Cloudflare configuré par l'application. Le Worker peut ensuite transmettre ces données au fournisseur de modèle d'IA défini dans sa configuration.

Le fournisseur effectivement utilisé, les durées de conservation côté Worker et fournisseur, les éventuelles utilisations secondaires et les modalités de suppression doivent être précisés par l'exploitant à partir de la configuration réelle du Worker et des contrats applicables. Ne transmets pas de données personnelles ou confidentielles dans le tuteur.

4. Services tiers et hébergement

Le site est publié via GitHub Pages. Le rendu des formules charge MathJax depuis jsDelivr ou cdnjs ; ces services peuvent recevoir les informations techniques habituelles nécessaires à la requête (notamment l'adresse IP et les informations du navigateur), selon leurs propres politiques.

5. Cookies, publicité et mesure d'audience

Le code de cette version ne met pas en place de compte utilisateur, de paiement, de publicité intégrée ni d'outil de mesure d'audience propriétaire. Les services tiers d'hébergement et de distribution de ressources peuvent toutefois traiter des données techniques selon leurs propres conditions.

6. Contact et exercice des droits

Avant toute diffusion commerciale, cette section doit être complétée avec l'identité et les coordonnées du responsable du traitement, ainsi que les modalités permettant d'exercer les droits applicables. Les informations relatives au fournisseur IA et à la conservation des conversations doivent également être vérifiées et ajoutées.

7. Modifications

Cette page sera mise à jour si les fonctionnalités, les prestataires ou les traitements de données évoluent.

Important : cette politique est une base de transparence technique pour la version bêta. Elle n'est pas une attestation de conformité RGPD et ne doit pas être considérée comme finalisée pour une offre commerciale.
